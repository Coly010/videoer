# Breathe Again awareness conformance campaign

This is Videoer's third campaign class and its first horizontal environmental public-awareness film. It is intentionally distinct from both the narrative book trailer and the vertical product launch.

```bash
npm run video -- cinematic-campaign validate campaigns/breathe-again-awareness-conformance/cinematic-campaign.yaml
npm run video -- cinematic-campaign build campaigns/breathe-again-awareness-conformance/cinematic-campaign.yaml
```

The campaign adds no TypeScript orchestration or asset factory. Its city corridor, tree line, symbolic seedling, materials, semantic camera anchors, four-shot grammar, typography, soundtrack, gates, and exact 12-second edit are all campaign data interpreted by the reusable declarative builder.
