# Nocturne programme-announcement reuse

This separate four-second campaign resolves `editorial.nocturne-event-lockup@1.0.0` unchanged from the first-class editorial library. It represents the natural reason to reuse editorial work: the same approved event identity must remain pixel-identical across another deliverable rather than being retyped or approximately recreated.

The campaign also directly reuses `lighting.nocturne-gallery@1.0.0`, while declaring new programme-stage geometry, camera data, soundtrack, and edit timing. Both asset decisions must be `reuse`, with zero editorial or lighting adaptation and zero campaign-specific orchestration source files.
