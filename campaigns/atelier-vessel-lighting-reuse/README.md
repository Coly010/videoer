# Atelier Vessel lighting reuse

This six-second square product teaser directly reuses `lighting.nocturne-gallery@1.0.0` with no adaptation. The rig was derived and published by the longer Nocturne cultural-exhibition trailer, so this campaign proves that the resulting asset is useful outside its originating venue, duration, aspect ratio, and campaign genre.

The campaign contains no campaign-specific orchestration source code. Geometry, semantic product shots, deterministic sound, typography, library resolution, lighting application, Blender rendering, and exact edit assembly all use the shared declarative system.

Both shots evaluate the 316-triangle product stage at 37 camera-path samples before rendering, then require Blender's frame-baked semantic target and lens evidence to match the same renderer-independent sampler.
