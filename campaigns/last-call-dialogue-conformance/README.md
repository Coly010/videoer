# Last Call dialogue conformance

This campaign is a consumer of Videoer's reusable spoken-performance system, not the implementation of it. It exercises a library character adapted with sparse mouth-only visemes, an open-source speech cue used as the single source of truth for audio and native phoneme timing, frame-exact morph animation, Blender shape-key deformation, close-up rendering, and ordinary deterministic edit assembly.

Its acceptance criteria are intentionally transferable: the declarative builder must reject missing speech morphology, clipped dialogue, non-frame-exact cue intervals, or audio/facial placement drift beyond one frame. The same geometry, motion, soundtrack, timeline-composition, renderer, and verification contracts are available to trailers, product films, character campaigns, explainers, and other campaign grammars.
