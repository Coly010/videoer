# Rainwalk Banner library reuse

This two-second 16:9 campaign directly reuses the verified VFX, material, and fitted-clothing releases created by the square Rainwalk campaign. It performs no VFX, material, or clothing adaptation and contains no bespoke orchestration source.

Its purpose is to prove the production-economics loop: the first cross-domain campaign creates and verifies reusable inventory; this subsequent campaign selects and assembles those assets into a different format with materially less creative data and no repeated derivation work.
