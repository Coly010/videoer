# After Hours character conformance campaign

This fourth campaign proves that the declarative path can resolve a verified recurring character and gait from the shared library, generate a target-derived turn from an environment attachment, compose layered motion, enforce biomechanics and travel direction, and render a complete character-led campaign without bespoke orchestration code.

```bash
npm run video -- cinematic-campaign validate campaigns/after-hours-character-conformance/cinematic-campaign.yaml
npm run video -- cinematic-campaign build campaigns/after-hours-character-conformance/cinematic-campaign.yaml
```

The campaign is an original horizontal fashion/identity teaser on an abstract night transit platform. It intentionally avoids the benchmark's bookshop, door, book, and narrative grammar while exercising the same recurring-character continuity and corrected forward-walk verification.

The accepted delivery is 640×360, 24 fps, 240 frames, and exactly 10.000 seconds with H.264/yuv420p video and AAC stereo 48 kHz audio. The soundtrack measures −17.6 LUFS integrated and −7.6 dBFS true peak. The walk travels 1.66 m with 0.99995 alignment to canonical body-forward, while animated-mesh camera projection keeps the complete character between 67.6% and 68.8% of frame height at the declared landmarks.

Two rejected renders are part of the system evidence. Cameras outside the platform shell produced black frames and were corrected without relaxing visibility limits. A later walk was visible and moved forward but cropped the legs; that failure produced the reusable `subject-framing` render gate instead of a campaign-specific exception.
